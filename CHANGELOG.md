# Changelog

## 0.1.0 (unreleased)

- First version: live reStructuredText preview with no Python, no Sphinx and no setup.
- Scroll sync both ways, double-click to jump to the source line, warnings in the Problems panel.
- Grid tables with spans, simple tables, csv-table, list-table, admonitions, footnotes, citations, substitutions, all list types.
- Code colors, KaTeX math, local pictures and figures, include and literalinclude inside the workspace folder.
- Sphinx directives and roles shown as labelled boxes and links instead of errors.
- Outline, VS Code and GitHub looks, Export HTML (one self-contained file).
- Support links and a related tools list. One rating request after a few days of use (setting `rstPreview.askForRating`).
