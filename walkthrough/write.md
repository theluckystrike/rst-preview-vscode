# Type and see it update

- The preview renders again a moment after you stop typing. Only the parts that changed are redrawn, so the page does not jump.
- The preview scrolls with the editor. Scroll the preview and the editor follows.
- Double-click a paragraph, a list or a table in the preview to put the cursor on its line.
- If a line has a problem, for example a title underline that is too short or a link to a target that does not exist, it shows in the Problems panel with its line number. The preview keeps showing the rest of the file.
