# Outline, style and export

- The Outline button opens a list of the sections next to the page. Click one to jump to it. The Outline view of VS Code and the breadcrumbs show the same sections.
- The VS Code button uses the colors of your theme. The GitHub button shows the look of a README.rst on GitHub, light or dark with your theme.
- Export HTML saves one .html file. Pictures, math and code colors are inside the file, and it opens in any browser without a network.
- Source goes back to the .rst file.
